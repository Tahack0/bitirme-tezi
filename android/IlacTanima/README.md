# İlaç Tanıma Android uygulaması

Bu klasörü Android Studio’da açıp Gradle Sync işlemini çalıştır. Arşiv Gradle Wrapper’ın yalnızca yapılandırma dosyasını içeriyor. Android Studio’da projeyle uyumlu yerel Gradle kurulumu kullanabilir veya Wrapper dosyalarını yeniden oluşturabilirsin.

YOLOv11n TFLite modeli, etiketler ve SQLite ilaç kataloğu `app/src/main/assets/` altında yer alır. Kamera özelliğini test etmek için Android cihaz kullan.
